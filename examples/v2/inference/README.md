# Inference Examples

Arena v2 inference (serving) support is planned for a future release.

Planned templates:
- vllm.yaml — vLLM high-throughput inference
- tensorrt-llm.yaml — TensorRT-LLM optimized inference
- triton.yaml — NVIDIA Triton Inference Server

See the [design document](../../../keps/arena-v2/README.md) for the roadmap.
